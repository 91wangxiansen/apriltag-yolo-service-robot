# 基于 AprilTag 与 YOLO 的室内服务机器人

面向居家陪护场景的本科毕业设计原型。系统将视觉定位、人体感知和移动底盘控制串联起来，实现室内人体跟随、静态避障、疑似跌倒检测与提醒。

## 系统架构

- **上位机（Python）**：使用 AprilTag 作为室内定位基准，并用 YOLO 做目标检测和人体姿态估计。跟随程序根据人机相对位置计算导航目标，经 UDP 下发。
- **机器人端（ROS）**：接收 UDP 导航目标并发布给 `move_base`，由导航系统控制底盘移动与避障。
- **底盘固件（STM32 / Keil MDK）**：包含电机、编码器、PID 控制和串口通信等模块。
- **语音与告警（FastMCP）**：提供机器人状态查询接口，并支持将疑似跌倒提醒推送到企业微信群。

## 运行准备

上位机脚本依赖 OpenCV、NumPy、Ultralytics 和 pupil-apriltags。运行视觉脚本前，请根据设备配置摄像头，并设置 `detact.py` 中的 YOLO 权重路径。原项目目录未包含自训练检测权重 `best.pt`。将上位机脚本在同一工作目录运行，以共享 `robot_status.json`。机器人端需要配置 ROS、`move_base` 和底盘驱动，并核对车端 IP 与 UDP 端口。

如需启用企业微信告警，请在启动 `fall_alarm_mcp.py` 前设置环境变量 `WECHAT_WEBHOOK_URL`。如果告警服务和视觉脚本使用不同的工作目录，可通过 `ROBOT_STATUS_FILE` 指定同一份状态文件。
